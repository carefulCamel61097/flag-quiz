# Flag assets

Generated — **do not edit by hand**. Run `npm run build:flags` to regenerate.

250 SVG flags at a uniform `0 0 640 480` viewBox, named by lowercase
ISO 3166-1 alpha-2 code (plus `xk` for Kosovo).
